# Farmàcia la Menstruació

A playful Art Nouveau pharmacy for period pain. Three remedies sit on a celadon-green shelf: Advil, a pair of wool socks and a bag of dried cranberries. Click one to read its leaflet: what it is, why it might help, and whether it was ever tested on women, and on which women.

An art project, not a real pharmacy and not medical advice.

## Run it

It is a static page with no build step. Open `index.html`, or serve the folder:

```
python3 -m http.server
```

## Files

- `index.html` the shelf and the leaflet dialog
- `style.css` all styling
- `data.js` leaflet content and sources
- `script.js` opens the leaflets
- `img/` product cut-outs and generated textures
- `fonts/` Smythe and Lato, self-hosted (SIL Open Font License)
